Privacy policy – "mimictrace backup"

Last updated: 23 November 2026.

Who uses the application

"mimictrace backup" is a private tool of the mimictrace thesis project. Its only user is the author, Pavlo Kulakov, who authorises it for his own Google account.

What the application accesses

The application requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. With this scope it can see and change only the files that it has created itself. It cannot read any other file in the Google Drive of the account.

What it stores and why

It uploads encrypted backups of the project's research data (public DNS zone data and derived statistics) to the author's own Google Drive. The files are encrypted before upload; Google stores only ciphertext and encrypted file names.

What it does not do

  • It does not collect personal data about anyone.
  • It does not share, sell or transfer any data to third parties.
  • It does not use Google user data for advertising, profiling or training of machine-learning models.

Credentials

The OAuth token is kept only on the author's own server and in the author's password manager. Access can be revoked at any time at myaccount.google.com/permissions.

Use of Google user data

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
